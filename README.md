# Employees Dataset Cleaning Project

## Project Description
This project focuses on cleaning and formatting an Employees dataset using Microsoft Excel.

## Dataset
The dataset contains employee information such as:
- First Name
- Gender
- Start Date
- Last Login Time
- Salary
- Bonus %
- Senior Management
- Team

## Cleaning Performed
- Removed duplicate rows.
- Replaced missing values in **First Name** and **Team** with `Unknown`.
- Adjusted column widths for better readability.
- Fixed the display of date/time values that appeared as `###`.
- Formatted **Salary** as currency.
- Formatted **Bonus %** as a percentage.

## Files
- `employees_cleaned.xlsx` — cleaned Excel dataset.
- `Employees_Dataset_Cleaning_Report.md` — cleaning report.

## Tools
- Microsoft Excel
- GitHub

## Outcome
The final dataset is cleaner, more consistent, and easier to read and work with.
